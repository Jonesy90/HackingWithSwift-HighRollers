# Hacking With Swift - High Rollers

## Description:
This HWS challenge requires me to create an app that lets users roll dice, and also lets them see results from previous rolls. Some of the optional tasks are:
1. Let the user customise the dice that are rolled (e.g., how many of them and what type).
2. Show the total rolled on the dice.
3. Store the results using JSON or SwiftData.
4. Add haptic feedback when the dice is rolled.
5. Make the value of the dice flick through possible values before settling on the final figure.
